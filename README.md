# LeetCode Helper Extension

This Chrome extension assists users with LeetCode challenges by providing helpful tools and features directly on the LeetCode website.

## Features

- **Background Script**: Manages events and communication between different parts of the extension.
- **Content Script**: Interacts with the LeetCode web pages to manipulate the DOM and provide assistance.
- **Popup Interface**: A user-friendly popup that appears when the extension icon is clicked, allowing for easy access to features.
- **Utility Functions**: Common tasks are handled through utility functions for better code organization and reusability.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd leetcode-helper-extension
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Load the extension in Chrome:
   - Go to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked" and select the project directory.

## Usage

Once the extension is loaded, click on the extension icon in the Chrome toolbar to open the popup and access its features while solving LeetCode challenges.
